# New7z 隐私政策 / Privacy Policy

生效日期 / Effective date: 2026-11-07

## 中文

New7z 是一款本地运行的 Windows 压缩与解压工具。本政策说明应用如何处理与你有关的信息。

**我们不收集任何个人信息。** 应用没有账号系统，不收集姓名、邮箱、设备标识符、位置或使用统计，也不包含分析、广告或遥测组件。

应用在本地保存的数据仅包括：

- 应用设置（主题、语言、是否自动检查更新）；
- 最近打开的压缩包列表；
- 你在应用内选择的品牌图标副本。

这些数据保存在本机的 `%LOCALAPPDATA%\New7z` 目录，不会上传到任何服务器。你可以随时删除该目录来清除它们。

你打开的压缩包内容仅在本地被读取、创建或解压，指向你明确选择的路径。应用不会扫描、上传或分享文件内容。

**网络访问：** Microsoft Store 版本不发起任何网络请求。GitHub 分发版本仅在你允许时访问 GitHub Releases 检查新版本，并下载更新安装包用于校验和安装；该功能可在设置中关闭。

**权限：** 应用声明文件关联和资源管理器右键菜单，用于在「打开方式」和右键菜单中提供入口。这些权限不涉及数据收集。

**第三方：** 应用内置的开源 7-Zip 引擎在本地运行，不进行网络通信。

**儿童隐私：** 应用不面向儿童，也不收集任何年龄信息。

**政策变更：** 本政策如有更新，将发布在此页面并注明生效日期。

**联系方式：** 如有疑问，请通过 https://github.com/outsideoftime/new-7z/issues 联系我们。

## English

New7z is a local Windows archive tool. This policy explains how the app handles information about you.

**We do not collect any personal information.** The app has no accounts and collects no names, email addresses, device identifiers, location or usage statistics. It contains no analytics, advertising or telemetry components.

Data the app stores locally:

- app settings (theme, language, whether to check for updates);
- the list of recently opened archives;
- a copy of a custom brand icon you pick inside the app.

This data lives in `%LOCALAPPDATA%\New7z` on your machine and is never uploaded. You can delete that folder at any time to remove it.

Archives you open are read, created and extracted locally, at the paths you explicitly choose. The app never scans, uploads or shares file contents.

**Network access:** the Microsoft Store build makes no network requests. The GitHub-distributed build contacts GitHub Releases to check for updates and downloads an installer for verification and installation, only when you allow it; this can be turned off in Settings.

**Permissions:** the app declares file associations and an Explorer context menu so it can appear in "Open with" and in the right-click menu. These permissions involve no data collection.

**Third parties:** the bundled open-source 7-Zip engine runs locally and performs no network communication.

**Children's privacy:** the app is not directed at children and collects no age information.

**Changes:** updates to this policy are published on this page with a new effective date.

**Contact:** questions are welcome at https://github.com/outsideoftime/new-7z/issues.
