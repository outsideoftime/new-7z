# New7z 功能设计 · v0.1

日期：2026-11-03。状态：功能设计基线，原生开发版已启动；实际完成项与限制见 `docs/工程说明.md`。

## 1. 产品定义

New7z（暂定名）是一款基于 7-Zip 技术、面向 Windows 11 的本地压缩工具。核心任务是「打开查看 → 选择内容 → 解压」和「选择文件 → 设置压缩 → 生成压缩包」。提供常用默认值，同时允许展开专业参数。无账号、无广告、无云上传；本轮以简体中文桌面端为范围。

用户包括日常收发文件的办公用户，以及处理大文件、多卷和密码包的开发者与创作者。产品采用 Windows 11 Fluent Design；原生开发版已采用 WinUI 3 + C# 界面与本地 DLL 引擎，独立 Worker 隔离仍为后续计划。

**能力策略：** UI 根据实际引擎能力启用操作。原生开发版已接入完整 7-Zip 引擎，7z/ZIP 创建、读取、解压与测试已做集成验证；HTML 原型仍是示例数据。RAR 仅读取/解压，不提供创建，当前尚缺 RAR 样本集成验证。其他格式按实际引擎能力与验收结果开放。

参考：[LZMA SDK 官方说明](https://www.7-zip.org/sdk.html)、[完整 7-Zip 格式说明](https://www.7-zip.org/)。发布前应根据最终分发的组件核对其许可证和随包声明，本稿不把 SDK 与完整 7-Zip 的授权条件混为一谈。

## 3. 功能分期

| 模块 | P0：首个可用版本 | P1：完整工具 | P2：增强 |
|---|---|---|---|
| 入口 | 打开压缩包、新建压缩、文件拖放 | 资源管理器菜单、文件关联 | 命令行调用 |
| 浏览 | 目录、文件列表、面包屑、排序、当前目录搜索、多选、属性、图片/纯文本预览、上下文菜单 | 多压缩包标签、包内搜索、更多预览格式 | 嵌套压缩包临时浏览 |
| 压缩 | 7z / LZMA2、级别、输出位置、密码与文件名加密（接入验证后） | ZIP、分卷、预设、固实/字典/线程参数 | 自解压、格式转换 |
| 解压 | 全部/选中、输出目录、冲突处理、密码、校验失败反馈 | 批量独立目录、文件名编码选择 | 智能目录规则 |
| 任务 | 排队、进度、取消、结果和重试 | 并发上限、速度/内存配置、完成通知 | 定时任务 |
| 校验 | 压缩包完整性测试 | SHA-256 计算/比较 | 批量校验清单 |
| 外观 | 系统/浅/深主题、应用内图标替换、恢复默认 | 图标包、格式映射、资源管理器图标注册 | 图标包导入导出 |
| 设置 | 默认压缩级别、默认解压规则、最近记录开关/清空 | Shell 集成、关联管理、临时目录 | 国际化 |

P0 不做压缩包内直接删除、重命名、拖入更新，也不自动删除源文件。后续更新包操作需先生成新归档、校验成功后原子替换，避免中途破坏原包。暂停并非统一的引擎能力：仅在有可靠协作式暂停协议时展示；原型中的暂停只是任务状态演示，正式应用不能用挂起进程冒充安全暂停。

## 5. 主要用户流程

### 5.1 打开与浏览

1. 「打开压缩包」、双击关联文件或拖入归档文件。
2. 识别实际格式；扩展名与文件头不一致时按探测结果展示并说明。
3. 加载时显示「正在读取目录…」，可取消；失败保留可读路径和原因。
4. 成功显示文件名、原始大小、压缩后大小、类型、修改时间；未知值显示「—」。
5. 文件夹双击/Enter 进入，面包屑返回；选择变化只更新属性与选中计数。
6. 当前目录搜索有清除入口，无结果提供清空；排序后保持选择的条目 ID。

包内图片和纯文本纳入 P0，可在软件内只读预览，无需用户先完整解压。正式版按需解码所选条目到有大小限制的内存流；确需落盘的解码器使用本任务专用临时目录。不会自动运行文件或调用外部应用。

### 5.1a 图片与文本预览

**入口与范围：** 文件列表的图片/文本名称、选中单个文件后的「预览」命令、属性中的「预览文件」使用同一预览窗口。原型点击名称打开，正式版可保留资源管理器式单击选择、双击预览。文件夹继续进入目录；多选时不自动预览。关闭后保留目录、搜索、排序和选择，焦点回到触发控件。

| 类型 | 首版范围 | 交互 |
|---|---|---|
| 图片 | PNG、JPEG、WebP、BMP、GIF 静态首帧（最终以原生解码器为准） | 适应窗口、25%/50%/100%/200%、原始尺寸滚动、尺寸与格式信息 |
| 纯文本 | TXT、Markdown、日志、CSV、JSON、XML、YAML、INI 和常见代码文件 | 只读、行号、自动换行、查找高亮/匹配数、编码识别与手动选择 |
| 其他 | PDF、Office、视频、可执行文件等不在 P0 预览范围 | 显示格式原因与「解压这个文件」，不会自动启动关联应用 |

- 前后切换限定当前可见目录中可预览的图片与文本，不跨目录、不悄悄跳出搜索结果；按钮和 `Alt+←/→` 等效，首尾禁用，不循环。
- 图片默认快速预览上限为解压后 32 MB、解码后 4000 万像素；超过任一限制时保留文件信息并提供解压入口。限制检查同时使用条目元数据和实际流字节数，防止错误元数据绕过。
- 文本默认读取前 2 MB 或前 100,000 行，先到为止，明确标记截断与已读取范围；不将整个大日志一次性加载。自动编码优先识别 BOM，再尝试 UTF-8；用户可切换 GB18030 / UTF-16，解码失败保留内容与提示。原型的编码切换只演示选择与状态，不模拟真实字节解码。
- HTML、SVG、Markdown、XML 与代码按文本显示；不执行脚本、不加载文内远程链接或嵌入内容。首版不渲染 SVG 图片。文本查找支持中文输入法与清空，不改写源文件。
- 读取阶段显示可取消进度；快速切换文件取消旧读取或丢弃旧结果。固实包不承诺即时预览，使用「正在准备预览」反馈，避免误认为无响应。
- 加密条目通过共享密码输入流程读取，密码仅当前归档会话有效；密码错误、CRC 错误、损坏图片、二进制伪装文本分别反馈，不把乱码当作成功。空文本显示「文件为空」。
- 关闭窗口终止当前预览读取、释放图像/流与本次临时文件；退出崩溃后仅清理应用拥有的预览缓存目录。预览不修改源归档，不写入历史内容或密码。

原型新增图片、文本、加载、读取失败/重试、不支持格式与超大图片状态。图片使用 `prototype/assets/preview-cover.svg` 作为受控、代码绘制的内置示例，列表中的 `.png` 是模拟归档名称；真实用户 SVG 预览仍不在首版范围。文本也是内置示例，未读取真实压缩包。

### 5.2 新建压缩包

1. 选择文件/文件夹（原生选择器支持多选），或拖入普通文件。
2. 填写归档名、输出目录、格式和压缩级别；默认 7z、标准、LZMA2。
3. 常用参数：标准 / 更快 / 更小；展开高级设置后才显示字典大小、线程、固实、分卷。
4. 密码默认隐藏、不持久化；有密码时可选加密文件名。ZIP 不提供文件名加密；不同格式调整可用参数并保留适用值。
5. 创建前检查输入、文件读权限、输出写权限、源/目标互相包含、已存在归档和可用空间。内存预测来自引擎，不展示虚构精确值。
6. 开始后关闭弹窗，任务中心可追踪；重复点击不能重复排队。
7. 成功后显示「打开所在文件夹 / 查看压缩包」。失败保留配置，提供原因、日志和重新尝试。

推荐不含密码的设置预设可保存；文件名单、密码、路径不写入遥测。已有文件不可静默覆盖，需显示目标文件并确认替换或改名。

### 5.3 解压

1. 未选择条目时「全部解压」；有选择时明确「解压选中的 N 项」，另保留全部解压入口。
2. 默认输出到归档旁同名文件夹；不会在用户未选择时直接散落到当前目录。
3. 选择输出位置，可设「完成后打开文件夹」。
4. 冲突默认「每次询问」，可选跳过/自动重命名；覆盖必须明示，可「应用到本次剩余冲突」。
5. 密码错误允许重输；错误信息区分密码错误、归档损坏、磁盘空间不足、拒绝访问、缺少分卷。
6. 部分成功应列出成功/失败/跳过数，不能显示全量成功。保留成功输出，让用户决定是否重试失败条目。

正式实现必须防止路径穿越、绝对路径写入、重解析点/符号链接逃逸。写入前规范化并校验每个目标仍在用户选定目录内。预检展开大小、条目数和剩余空间，未知大小时也要有运行时配额/取消能力。不会自动执行内容。临时输出采用本任务独立目录，仅清理该任务创建的临时文件。

### 5.4 任务与恢复

| 状态 | 界面 | 可用操作 |
|---|---|---|
| 等待中 | 队列位置、任务名称 | 取消 |
| 准备中 | 不定进度、正在扫描 | 取消 |
| 运行中 | 当前阶段、百分比（可测时）、字节、速度、估算剩余时间 | 取消；具备能力才有暂停 |
| 等待输入 | 需要密码/同名冲突，任务停在安全点 | 处理 / 取消 |
| 已暂停 | 保留进度与原因 | 继续 / 取消 |
| 完成 | 实际输入/输出大小、耗时、结果路径 | 查看结果 / 打开位置 |
| 部分完成 | 成功/失败/跳过数与错误明细 | 查看详情 / 重试失败项 |
| 失败 | 可理解的原因、详细错误码 | 修改配置 / 重试 |
| 已取消 | 取消阶段、保留输出说明 | 重新创建任务 |

排队任务的输入清单创建快照；正式运行再次检查源文件是否存在/变化。UI 和引擎进程分离，崩溃后标记「中断」，不能假装断点续压。重试是重新启动任务；是否复用输出必须按操作语义明确实现。并发默认 1，避免多个高内存压缩任务争抢资源。日志不含密码，历史默认只保存在本机并提供清空入口。

## 6. 可替换图标设计

三个作用域必须分开：

| 作用域 | 用户可替换内容 | 生效方式 |
|---|---|---|
| 应用内 | 左上角品牌、空状态主图、文件类型图标 | 应用内立即预览并应用 |
| 可执行程序 | EXE/快捷方式/任务栏品牌图标 | 独立构建资源；运行时不承诺修改已签名 EXE，任务栏可能需重新启动/固定 |
| Windows 文件关联 | `.7z`、`.zip` 等系统文件类型图标 | P1 单独操作，仅处理已选择关联，系统可能有缓存，不冒充立即全局更新 |

图标包结构候选：

```text
IconPacks/<pack-id>/
  manifest.json
  app.png
  archive-default.png
  archive-7z.png
  archive-zip.png
  archive-rar.png
```

`manifest.json` 建议字段：`schemaVersion`、`id`、`name`、`author`、`icons`（逻辑 ID → 相对文件路径）。禁止任意目录路径、URL、脚本和动态 DLL。首版自定义图片支持 PNG/ICO；JPEG 仅可作为应用内图片输入，SVG 在引入安全解析器前不开放。建议提供 16/20/24/32/48/64/128/256 尺寸的高质量版本；导入限制 10 MB、解码尺寸上限 4096 × 4096。

流程：选择图片/图标包 → 校验 → 浅/深与多个尺寸预览 → 应用 → 可随时恢复默认。映射缺失时回退格式默认图标，再回退通用归档图标。无权限/坏文件/不支持类型显示就地错误，不覆盖当前有效配置。图标替换永远不改变文件内容、格式支持或默认程序。

现有合集在原型设置页以裁切窗口预览原图；正式资源应重新导出独立透明文件，保留原 PNG。当前 Logo 自带深色方形背景，原型如实使用，不把它当透明素材。

## 7. Windows 集成与技术边界

正式版候选分层：

```text
WinUI 3 界面 → 应用服务（任务/能力/配置）→ 引擎适配器 → 独立 Worker
                                     └→ 图标资源服务
Shell 扩展 / 文件关联 → 受校验的启动参数 → 应用服务
```

- 引擎能力模型：可读取/创建格式、加密方式、更新支持、分卷、可靠暂停。UI 只从该表生成选项。
- 原型不是 WinUI 3 实现。HTML/CSS 仅用于评审布局与交互，无法展示真正的 DWM Mica、原生选择器、Shell 图标缓存和任务栏行为。
- 子进程参数使用结构化参数列表，不拼接 shell 字符串；密码不作为可被进程列表读取的明文命令行参数。优先使用本地 DLL/受控 IPC 的凭据传递方案并验证生命周期。
- 引擎事件：`ScanStarted`、`Progress`、`InputRequired`、`Completed`、`Failed`；取消有请求/确认两阶段，UI 不在引擎确认前报告已停止。
- x64 优先；ARM64 为独立编译与测试目标。语言/位数不从当前 SDK 目录结构直接推断已支持。
- 文件关联必须交由 Windows 允许的默认应用流程完成；应用内设置不能承诺强行修改系统默认项。

## 8. 验收标准与推进顺序

设计评审先确认：主导航与文件管理密度、浅深主题、压缩/解压弹窗、任务反馈和图标作用域。随后先完成引擎能力探针和最小 7z 压缩/解压链路，再接入原生 UI，最后接 Shell 集成。

P0 验收至少覆盖：中文/空格/长路径、空文件/空目录、大文件、多文件、密码错误、损坏包、缺分卷、磁盘满、无写权限、用户取消、进程中断、同名冲突、恶意归档路径、图标导入失败与恢复默认。所有性能数值来自测量；原型的大小、速度、进度均为明确标注的示例。

本轮交付：本功能设计、原型设计说明、共享视觉/交互规范、本地可点击原型、原型截图与验证记录。
