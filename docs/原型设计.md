# New7z 原型设计 · v0.1

日期：2026-11-03。入口：`prototype/index.html`，可直接用浏览器打开，无需安装依赖或发布网站。

## 设计方向

以 Windows 11 文件资源管理器的熟悉结构承接压缩工作：Mica 基底、连续内容层、命令栏、面包屑和紧凑列表。品牌蓝取自现有蓝色拉链 Logo，格式色只用在图标。个性集中在「归档属性」中的体积对照条，帮助理解归档前后大小，其他控件保持克制。

Mica 是长期窗口的底材，不等于整窗透明玻璃；Acrylic 用于短暂浮层，模态遮罩使用 Smoke。原型用 CSS 近似层级，不宣称实现系统材质。依据：[Windows 材质指南](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/materials)、[Mica](https://learn.microsoft.com/en-us/windows/apps/design/style/mica)。

## 页面与线框

### P01 主页

```text
┌ App Logo · New7z ──────────────────────── 窗口控件 ┐
│ 导航       │ 主页                   [打开] [新建压缩]│
│ 主页       │                                      │
│ 压缩包     │ 拖入压缩包查看，或选择文件创建压缩包      │
│ 任务中心   │ 支持说明 + 文件选择入口                  │
│            │                                      │
│            │ 最近使用                    搜索 / 清空 │
│            │ 图标 文件名    格式    大小    上次打开    │
│ 设置       │ 最近列表（空时显示打开入口）             │
└────────────┴──── 交互原型 · 示例数据 ────────────────┘
```

两个主入口按任务命名，不做统计仪表盘。最近记录展示完整名称，长路径可在详情中查看。原型点击「打开」进入示例包，拖入文件仅作为临时名称示例，不解析压缩内容。

### P02 压缩包浏览

```text
│ 归档图标 项目素材.7z                  [全部解压] │
│ [添加到新包] [测试]        [属性]                │
│ 根目录 > …                       搜索当前目录   │
│ □ 名称          大小  压缩后   修改时间 │ 属性    │
│ □ 设计稿/                              │ 7z      │
│ □ 产品说明.pdf                         │ 体积对照│
│ □ …                                    │ 方法    │
│ 选中数 / 条目数                        │ 操作    │
```

文件列表是主角，右侧属性宽 248 px，可收起；窄窗口移到列表下。选择文件时主操作改为「解压选中 N 项」。文件夹可以进入，面包屑恢复根目录；搜索仅筛当前目录。图片和文本可通过名称、命令栏或属性入口预览；删除与更新仍不在 P0。

### P03 新建压缩弹窗

宽 640 px，主体内部滚动，底部按钮固定。顺序：来源摘要 → 归档名称 → 保存目录 → 格式与压缩级别 → 高级设置 → 密码。高级设置折叠，避免首屏过密。7z 可选；ZIP 显示后续引擎接入提示，当前不可选。

输出名称错误在字段下解释并聚焦；密码默认隐藏，可切换显示；文件名加密只有启用密码时可选。原型接受名称与级别等设置并生成明确标注的模拟任务；不会生成真实归档。

### P04 解压弹窗

显示来源和范围，目标目录文本可编辑；「新建同名文件夹」默认选中。冲突策略采用原生下拉列表，由操作系统承担弹出层样式；默认每次询问。按钮用「开始解压」，成功转任务中心。原型提供「演示同名冲突」进入冲突状态，展示保留两者、跳过、替换和本次应用范围。

### P05 任务中心

进行中任务卡采用「名称 + 阶段 + 进度条 + 已处理/总量 + 操作」。模拟任务可暂停/继续与取消，取消需确认并说明未写入磁盘。完成后留在列表，失败示例支持重试；无任务时提供创建入口。任务可跨页面继续；页面底部持续标注模拟数据。

### P06 设置 / 外观与图标

主题为系统、浅色、深色单选；应用内即时预览。图标设置区左侧显示品牌图标与 16/32/48 尺寸，右侧提供「替换应用内图标」「恢复默认」。现有格式图标合集作为视觉素材预览。原型允许实际读取一张用户选择的 PNG/ICO 到当前浏览器会话并预览；不会修改 EXE、系统关联、任务栏或原始图片。

设置区明确区分应用内与系统图标，展示后续图标包映射规则，不能用一个按钮混淆全部作用域。

### P07 图片 / 文本预览

```text
┌ 项目封面.png                     关闭 ┐
│ 项目素材.7z / 项目封面.png      只读 │
│ [上一项] 1 / 2 [下一项]    缩放 / 编码│
│ 文本时：查找内容 [清空]    匹配数     │
│ ┌────────────────────────────────┐ │
│ │ 图片：适应窗口 / 原始尺寸       │ │
│ │ 文本：行号 + 只读正文 + 高亮    │ │
│ └────────────────────────────────┘ │
│ 图片尺寸 / 文本行数     读取失败演示 │
│ 内置示例 · 不修改归档       [关闭预览]│
└─────────────────────────────────────┘
```

使用现有共享模态，宽度上限 1120 px。图片默认完整显示，可缩放和滚动；文本使用等宽字体、可选自动换行和查找高亮。上一项/下一项只遍历当前可见目录中的可预览文件，Alt+方向键提供等效操作。窗口头与底部固定在模态滚动区之外；短视口仍可访问关闭和切换操作。

读取中有明确状态，快速切换时旧内容不得回填；失败可重试。PDF/FIG 等显示「暂不支持」与解压入口，大于 32 MB 的示例图片显示超限原因。文本中的 HTML 标签按文字显示。原型使用受控示例图与内置 README，不读取真实归档；编码选项只演示状态，正式限制与缓存方案见功能设计 §5.1a。

## 视觉规格

设计值以工程根目录 `DESIGN.md` 为规范、`prototype/tokens.css` 为运行映射。推荐评审视口 1440 × 960；默认主窗口最小设计目标 900 × 620 DIP。浏览器窄屏用于检查裁切与内容可达性，并非承诺移动端产品。

| 维度 | 规则 |
|---|---|
| 字体 | Segoe UI Variable / Segoe UI / Microsoft YaHei UI；数字等宽 |
| 字号 | 标题 28；区块 18；正文/控件 14；辅助 12 |
| 间距 | 4 px 基础节奏，页面边距 32，列表行高 52 |
| 圆角 | 控件 4，内容卡 8，主窗/弹窗 12 |
| 强调 | Windows 蓝；主操作每个区域一个，选中导航有短竖线 |
| 表面 | 导航淡云母底、内容近白，依靠层级/细描边而非大量阴影 |
| 暗色 | 同一布局与信息层级；文本/边界/选中态使用独立语义色 |
| 图标 | 工具图标为内联 SVG 线性图形，归档格式为代码原生文件图标；现有 PNG 如实用于品牌/素材预览 |
| 动效 | 120–180 ms 状态过渡；尊重 reduced-motion，无装饰性持续动画 |

## 一致性与状态

- 导航稳定：主页、压缩包、任务中心、设置始终同位置。
- 弹窗统一使用 HTML `<dialog>` 模态语义；提交、取消、Escape 和焦点恢复一致。
- 搜索支持中文输入法、即时本地筛选和可访问的清除按钮。
- 文件选择显示明确数量；切换目录/搜索时清空选择，防止对不可见条目误操作。
- 按钮具备 hover、pressed、focus-visible、disabled；不能只靠颜色表达状态。
- 非可用功能使用原因说明，不放置无响应按钮。
- 表格内部横向滚动；全局滚动条可见。弹窗高度受视口约束，底部操作始终可达。
- 输入错误在原位保留，状态提示使用共享 live region；重要错误不会只存在于短暂提示。

## 原型可交互范围

右键菜单新增 8 种场景设计，见 [右键菜单设计](右键菜单设计.md) 与 `prototype/context-menu-design.html`。应用原型的列表可实际右键，也有「更多」入口；菜单共享预览、解压与属性流程。资源管理器菜单仅作场景演示，尚未注册到 Windows。

可切换四个导航、打开示例包、浏览文件夹、排序、筛选、勾选、查看属性、预览图片/文本、提交压缩/解压配置、运行模拟任务、取消/重试、演示冲突、切换主题、替换应用内图标及恢复默认。原型不实现真实解压、路径选择器、Shell 集成、注册表写入或完整引擎接入。

交互数据仅在内存保存；刷新恢复示例，主题选项存储本地偏好。自定义图标仅当前页面有效。键盘可操作全部主要按钮和原生控件；原生应用阶段需另外验收 Narrator、DPI/多显示器、系统材质降级和窗口 Snap。
