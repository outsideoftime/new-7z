# New7z 原生工程 · 开发版 0.1

日期：2026-11-03。本工程已开始实际功能开发，HTML 原型继续保留作为设计参考。

## 运行

直接运行 `artifacts/app/New7z.App.exe`。该目录包含 .NET、WinUI 运行库及本地 7-Zip 引擎，应整体保留；不用安装 7-Zip，不调用系统 PATH 下的压缩程序。

可将压缩包拖入窗口，或使用「打开压缩包」。双击目录进入，双击图片/文本或按 Enter 预览，也可选中后点「预览」。选择多个条目后可解压选中项。新建压缩支持选择多个文件与文件夹，输出 7z 或 ZIP，密码通过内存传给原生接口，不出现在进程命令行。

## 结构

```text

src/New7z.Core/          归档服务、P/Invoke、路径检查、文本解码
native/New7z.Native.cpp 本地 C ABI 桥接，直接调用 7z.dll 接口
native/New7z.Shell.cpp  Explorer IExplorerCommand 原生 COM 扩展

7zSdk/Source/           用户提供的 7-Zip 26.05 完整源码
tests/New7z.Integration/真实引擎集成测试程序
scripts/                编译引擎、发布应用、运行测试
artifacts/native/x64/   编译后的 7z.dll、New7z.Native.dll
artifacts/app/          自包含 x64 开发版

```

构建环境：.NET SDK 10.0.403；Visual Studio C++ x64 工具链；Windows SDK。WinUI 的 WinUI 组件包 1.8.260803003 由 NuGet 还原，版本固定在工程文件中。

```powershell
# 完整编译：需要本机 C++ 编译工具
./scripts/build.ps1

# 仅更新应用：已编译好的引擎保持不变
./scripts/build.ps1 -SkipNative

# 真实归档集成检查
./scripts/test.ps1
```

`build-native.ps1` 通过 vswhere 查找 C++ 工具链，单独构建 `Format7zF`，随后构建自己的 C ABI 适配层。构建不安装或注册 7-Zip。现有 SDK 原件保留，源码解压到独立 `7zSdk/Source`。

## 本次已经实现

ZIP 性能更新：未加密 ZIP 的标准/更快模式通过 `FastZipWriter` 使用流式标准 ZIP/Deflate 编码，保留 Core 的路径与来源检查、临时输出和最终提交。密码 ZIP、体积优先 ZIP、全部 7z 继续使用原生 7-Zip；读取/预览/解压也仍使用 7-Zip。进度通知限频不降低取消检查频率。指定 STEP 样本与前后计时、体积权衡及 37 项回归见 [ZIP 性能优化](ZIP性能优化.md)。

- 读取引擎支持的归档格式、中文文件名、目录与隐式目录；当前目录搜索、多选和路径返回。
- 7z/ZIP 创建、压缩级别、密码、7z 文件名加密；输入目录递归、空目录、输出重名检查。
- 全部/选中解压，默认保留两者，可选跳过，替换需二次确认；单个输出先写临时文件，成功后提交。
- 压缩包内修改（仅 7z/ZIP）：添加文件或整个文件夹、删除条目（可多选，Delete 键等效）；同名条目先确认替换；整体重写到临时文件，成功后替换原包，取消或失败保留原包。删除前按最新列表解析条目，外部修改过的包会提示重新打开。
- 拖动解压：把所选条目拖到资源管理器或桌面文件夹；条目先解压到 `%TEMP%\New7z-drag-*`，拖动结束后延时清理，共享冲突时保留并在下次启动清理超过两天的残留。
- 自动更新：启动时读取 GitHub Releases 最新版本，下载对应的 x64 安装包并按 `SHA256SUMS.txt` 校验，确认后退出并运行安装器；设置 → 应用更新可关闭自动检查或手动检查。
- 图片实际读取、原生解码、缩放与滚动；文本实际读取、编码选择、自动换行、行号、查找第一处匹配。
- 串行后台任务、真实回调进度、取消、完整性测试、错误原因与任务记录。
- Mica 基底、原生主题、PNG 应用内图标替换/恢复、最近记录本地保存。
- 拒绝路径穿越、绝对路径、NTFS ADS、Windows 保留文件名、符号链接和重解析点；禁止输出覆盖源归档。
- Windows 11 资源管理器现代右键：打开、解压到同名/当前/指定目录、完整性测试、新建压缩包及快捷 7z/ZIP；支持多选与中文路径。

## 当前实现与设计稿的差异

这是首个开发版，不把全部设计条目标记为已完成。

- 引擎运行在应用进程中的后台线程，原生 DLL 崩溃隔离的独立 Worker 尚未接入。
- 任务取消依赖引擎安全回调；没有不可靠的暂停/挂起功能。尚未提供任务配置编辑重试与会话重启恢复。
- 解压每个文件重新打开归档，固实大包性能待优化；尚未处理跨卷回调与批量密码缓存管理。
- 文本最大 2 MiB，超出时提示解压查看，暂不实现前缀截断读取；显示最多 100,000 行。图片最大 32 MiB、4000 万像素。SVG、PDF、Office 不内置渲染。
- 图片预览以系统实际支持的解码器为准；不承诺所有 WebP/特殊图片编码在所有 Windows 环境可用。
- 文本查找选择第一处匹配并显示总数；全量匹配高亮、下一处匹配、语法着色尚未实现。
- 归档列表尚未实现列头排序、属性侧栏、多标签；窄窗口命令栏与长表格的布局还需继续打磨。
- 包内修改只支持 7z 和 ZIP；RAR、TAR、GZ、XZ、BZ2、ISO 仍只能读取和解压。拖动解压先把所选内容解压到临时目录，再交给 Windows 复制，大文件需要等待准备完成。
- 自动更新只处理 GitHub Releases 的 x64 安装包；安装器当前未做发布者代码签名，安装时仍可能出现系统提示；下载校验只证明文件与发布清单一致，不代表发布者身份已由证书认证。
- 自定义图标先支持 PNG，应用内持久生效：品牌图标与 7z、ZIP、RAR、TAR、GZ、BZ2、XZ、ISO 格式图标都可分别替换、恢复默认，格式图标用于「最近使用」等应用内位置，不修改资源管理器文件关联图标。默认 Logo 已去除背景并生成多尺寸 ICO，嵌入 EXE、任务栏窗口与 Shell 菜单扩展；7z、ZIP、RAR、TAR、GZ、BZ2、XZ、ISO 已从图标合集导出透明 PNG/ICO，并按格式注册文件关联 ProgID。用户 ICO 导入、动态替换 EXE 图标尚未接入。
- 当前只发布 x64；已提供当前用户 EXE 安装器、版本化运行目录、开始菜单/可选桌面入口、菜单注册及卸载流程。ARM64、受信任正式签名、自动更新尚未接入。Shell 可在设置中控制可见性和命令；设置中可修复菜单注册和文件关联。

后续优先解决大归档读取与任务取消压力测试，再补齐属性面板、排序、图标包与正式安装分发。

## 资源管理器右键注册

右键压缩、解压与完整性测试由 `ShellTaskWindow` 独立承载，`App.OnLaunched` 在创建窗口前读取并校验 `ShellRequest`，不会先构造/闪现主窗口。「用 New7z 打开」才实例化 `MainWindow`。小窗口不显示系统标题栏，图标与任务标题区域可拖动，底部提供关闭和打开文件夹，运行中取消/关闭等待引擎安全回调结束。压缩和解压设置直接显示在小窗口内部，密码不进入请求、日志或持久设置。

设置 → 资源管理器右键菜单提供总开关与八项命令勾选。配置通过「应用菜单设置」提交，禁用总开关保留命令选择；设置 → 任务弹出窗口可选手动关闭（默认）/自动关闭（仅成功时）。配置由 `ExplorerPreferencesStore` 保存在当前用户 `Software\New7z\Explorer`；Native DLL 在生成菜单时读取同一配置。设置 → Windows 自带压缩菜单可隐藏当前用户的 Windows 11 24H2+「压缩到」菜单，并在关闭设置或卸载时恢复 New7z 修改前的注册表值。

`scripts/test-shell-preferences.ps1` 对真实 COM 扩展进行独立注册表视图测试，覆盖总开关、命令筛选、空根菜单与无需重载的配置刷新；不会改动实际用户菜单设置。`scripts/test-popup-close.ps1` 覆盖手动成功保留、自动成功退出、自动模式失败保留；测试临时切换关闭策略，完成后恢复原值，不修改系统压缩菜单。Core 集成检查新增 Windows 压缩菜单的缺省、备份、恢复与外部修改检查，共 52 项。

`scripts/build-icons.ps1` 从现有 Logo 生成 16–256 px 七种 ICO 尺寸。`ApplicationIcon` 设置 EXE 资源，`WindowAppearance` 设置原生窗口图标，Shell DLL 和 Host 通过 RC 嵌入图标，`GetIcon` 返回扩展自身的资源路径。`scripts/test-icons.ps1` 检查三份二进制的图标组与 ICO 尺寸。

完整构建后执行 `./scripts/register-shell.ps1`，移除执行 `./scripts/register-shell.ps1 -Remove`。本机已在现有开发者模式下完成当前用户注册，不需要管理员权限，也未安装完整 7-Zip。Windows 11 主菜单直接显示 New7z，无需进入「显示更多选项」。普通文件/文件夹提供打包命令，归档提供打开、解压和完整性测试；文件夹空白处不增加入口。

注册引用 `artifacts/app` 的绝对路径；移动目录前移除扩展，移动后重新注册。开发脚本使用系统的开发包注册机制；正式分发仍需签名包和安装/卸载流程，不会由脚本更改安全设置。更新已加载的 Shell DLL 前先移除注册。

从 Explorer 启动时，应用可能带 sparse package 身份。发布同时保留 `New7z.App.pri` 与 `resources.pri`，避免系统扩展入口出现主题 XAML 资源找不到而普通双击正常的情况。实测证据见 [Explorer 右键验收](Explorer右键验收.md)。

复验命令：`./scripts/test-startup.ps1`。该命令会启动发布版并保持窗口打开供检查，不自动关闭用户窗口。
