# New7z 操作说明

New7z 是 Windows 11 上的本地压缩工具，基于 WinUI 3 和 7-Zip 引擎，离线运行，不需要另装 7-Zip。本页按使用顺序说明各项操作。

支持创建 7z、ZIP，读取和解压 7z、ZIP、RAR、TAR、GZ、XZ、BZ2、ISO；RAR 仅支持读取和解压。

## 1. 安装与启动

运行下载的 `New7z-<版本>-x64-Setup.exe`，按向导安装。默认装到当前用户目录 `%LOCALAPPDATA%\Programs\New7z`，不需要管理员权限，也不需要安装 .NET 运行库。

安装时可以选择创建开始菜单入口、桌面快捷方式，以及注册右键菜单和文件关联。升级安装会先删除旧版本的运行目录；被资源管理器占用的旧 Shell DLL 会在系统重启后删除。安装程序也会清理 New7z 自己的崩溃转储文件。

启动方式：

- 从开始菜单或桌面快捷方式启动；
- 双击已关联的压缩包（如 `.7z`、`.zip`）；
- 把压缩包或普通文件拖到主窗口。

## 2. 主窗口

左侧导航有**主页**、**压缩包**和**任务中心**，底部是设置入口。

- **主页**：打开压缩包、新建压缩、拖放区域，以及「最近使用」列表。最近打开过的压缩包会显示对应格式图标；每条可以「移除」，失效的条目会标注「文件不存在」，可用「清理失效记录」一次删除，也可以「清空最近记录」。
- **拖放**：拖入压缩包直接进入查看；拖入普通文件或文件夹会弹出「新建压缩包」。
- 底部状态栏显示当前是否就绪或是否有任务在运行。


## 3. 新建压缩包

1. 在主页点「新建压缩」，或直接把文件/文件夹拖进窗口。
2. 在对话框里点「添加文件」「添加文件夹」，可以分多次追加来源。
3. 填写「保存为」路径，或点「选择保存文件夹」。
4. 选择格式：**7z** 或 **ZIP**。
5. 选择压缩级别：**标准**、**更快**、**更小**。
6. 可选设置密码。7z 格式在输入密码后可勾选「加密文件名」。
7. 点「开始压缩」，任务会进入任务中心并显示进度。

说明：输出文件名已存在时会要求换一个名称；密码只用于本次任务，不会写入设置或日志。未加密 ZIP 的标准/更快模式使用快速编码，密码 ZIP、体积优先 ZIP 和 7z 使用 7-Zip 引擎。


## 4. 打开和查看压缩包

打开压缩包的方式：主页「打开压缩包」、双击已关联的压缩包、右键「用 New7z 打开」。

- 列表显示名称、原始大小、压缩后大小和修改时间，文件夹排在最前。
- 双击文件夹进入下一级；「↑ 上一级」返回；搜索框只筛选当前目录。
- 勾选文件或文件夹可多选；选中文件夹时会包含其下所有内容。点「全选」或按 Ctrl+A 可选中当前目录的全部条目。拖动时只拖动选中的条目：按在未选中的行上拖动只拖该行，按在已选中的行上拖动则拖动整个选择，与资源管理器一致。
- 双击文件或点「预览」查看内容：
  - 图片可以按「适应窗口 / 25% / 50% / 100% / 200%」缩放，并切换上一个、下一个；
  - 文本和代码文件（常见源码、配置、脚本扩展名，如 .cs、.py、.rs、.toml、Makefile）可以选择编码（自动 / UTF-8 / GB18030 / UTF-16 LE）、自动换行和查找，显示行号；
  - 预览是只读的，不会修改压缩包。
- 预览是独立窗口，会在主窗口所在屏幕居中并置于最前；拖动顶部标题区域即可移动，右上角 × 或 Esc 关闭；工具栏的按钮、编码选择和换行开关在同一行对齐。
- 「测试完整性」检查压缩包是否有损坏。
- **拖动解压**：选中一个或多个文件或文件夹，直接拖到资源管理器窗口或桌面上的文件夹，即可把内容解压到目标位置；文件夹会连同内部内容一起复制。New7z 会先把所选条目解压到临时目录，再由 Windows 复制到放置位置；文件较大时需要先等待准备完成。临时文件会在拖动结束后自动清理。
- **修改包内内容**（仅 7z 和 ZIP）：
  - 「添加文件」选择文件或文件夹并加入当前目录；文件夹会保留内部层级。
  - 勾选条目后点「删除」，或直接按 Delete 键。
  - 添加时遇到同名条目会先询问是否替换；删除前会列出条目并再次确认，删除内容不进入回收站。
  - 修改会先把完整内容写入临时文件，成功后替换原压缩包；取消或失败时原压缩包保持不变。加密压缩包需要密码才能修改。
  - 也可以把文件或文件夹直接拖进压缩包浏览窗口，效果与「添加文件」相同。
  - 其他格式（RAR、TAR、ISO 等）只能读取和解压，不能修改。


## 5. 解压

1. 点「全部解压」或先在列表中选中条目再点「解压选中」，会打开与右键任务相同的小窗口，不会切换到任务中心。
2. 在窗口中确认目标目录，可点「选择文件夹」更换。
3. 选择遇到同名文件时的处理方式：
   - **自动重命名，保留两者**（默认）；
   - **跳过已有文件**；
   - **替换已有文件**——选择后会再确认一次。
4. 加密压缩包会提示输入密码。
5. 窗口显示百分比进度；完成后提示解压完成和保存位置。

解压只写入选定目录，不会删除源压缩包；中途取消时已完成的文件保留，未完成的临时文件会清理。


## 6. 任务中心

压缩、解压、完整性测试都在任务中心排队执行，切换页面不会中断任务。

每个任务显示名称、目标位置、状态、百分比和进度条，并提供：

- **取消任务**：需要确认；已完成的输出保留，未完成的临时文件清理；
- **打开文件夹**：打开任务的目标目录。

## 7. 资源管理器右键菜单

在 Windows 11 上右键文件或文件夹，选择「显示更多选项 → New7z」；Windows 10 会直接出现在右键菜单中。

可用命令：

- 用 New7z 打开；
- 解压到同名文件夹（多选时显示「分别解压到各自文件夹」）；
- 解压到…（自选目录）；
- 解压到当前文件夹；
- 测试完整性；
- 新建压缩包…；
- 压缩为 7z；
- 压缩为 ZIP。

「解压到…」和「新建压缩包…」会在独立小窗口中完成设置，不打开主界面。小窗口顶部图标和标题区域可以拖动来移动窗口；任务运行中可以取消，关闭窗口会先确认；完成后可以打开文件夹。窗口默认保留，也可以在设置里改为成功后自动关闭。

## 8. 设置

设置页包含以下部分：

- **资源管理器右键菜单**：控制 New7z 菜单的显示与命令勾选，修改后点「应用菜单设置」生效；菜单异常时点「修复右键菜单注册」重新注册。
- **任务弹出窗口**：任务成功后「手动关闭（默认）」或「自动关闭」；自动关闭只在全部成功时生效，失败或取消会保留窗口。
- **Windows 自带压缩菜单**：Windows 11 24H2 及更新版本可隐藏系统自带的「压缩到」右键菜单。只影响当前用户；关闭开关或卸载时会恢复修改前的设置。
- **文件关联**：注册或修复文件关联；「选择默认应用」打开 Windows 的默认应用页面，由你决定是否让 New7z 打开某种格式。
- **界面语言**：跟随系统、简体中文或 English，切换后界面立即更新。
- **应用主题**：跟随系统、浅色或深色。
- **应用内图标**：替换应用内显示的品牌图标（PNG，最大 10 MiB、4096 × 4096），或恢复默认。
- **压缩文件图标**：分别替换 7z、ZIP、RAR、TAR、GZ、BZ2、XZ、ISO 在「最近使用」等位置显示的格式图标（PNG，限制同上），或恢复默认。只影响应用内显示，不修改资源管理器中的文件关联图标。
- **应用更新**：显示当前版本；「启动时自动检查并下载更新」默认开启。发现新版本后会从 GitHub Releases 下载安装包，与同版本发布的 `SHA256SUMS.txt` 比对校验，然后询问是否立即安装。点「检查更新」可手动触发。更新过程只访问 `github.com`，不上传本地文件或文件名。


## 9. 常见问题

**右键菜单没有出现**
先确认点的是「显示更多选项」；仍没有时，到设置里点「修复右键菜单注册」，再重新打开菜单。必要时重启资源管理器。

**文件图标没有更新**
Windows 的图标取决于当前默认程序。如果之前把 New7z 设为某种格式的默认程序，需要在「默认应用」里重新选择一次；系统图标缓存也可能需要重启资源管理器后刷新。

**压缩包打不开或提示密码错误**
确认文件和密码正确。加密包在输入密码后才能列出内容；密码不会保存到任何设置。

**添加或删除后压缩包被重新生成**
修改 7z/ZIP 需要整体重写压缩包。New7z 先写临时文件，成功后替换原文件；中途取消、失败或磁盘空间不足时原压缩包不变。若压缩包在打开后被其他程序修改，删除和添加会提示内容已变化，请重新打开后再操作。

**自动更新会做什么**
New7z 启动时访问 GitHub Releases 检查最新版本，下载安装包并校验 SHA-256，然后询问是否安装。可以在设置 → 应用更新中关闭自动检查，也可以手动点「检查更新」。压缩和解压本身不需要联网。

**卸载**
在 Windows「已安装的应用」中找到 New7z 卸载。只移除安装目录（包括所有版本的运行目录）和它注册的菜单、关联；应用设置和最近记录会保留。如果 New7z 曾隐藏 Windows「压缩到」菜单，卸载时会恢复原来的设置。

## 10. 文件位置

| 内容 | 位置 |
|---|---|
| 程序安装目录 | `%LOCALAPPDATA%\Programs\New7z`（运行文件在 `Versions\版本-哈希` 下） |
| 应用设置与最近记录 | `%LOCALAPPDATA%\New7z\settings.json` |
| 右键菜单与压缩菜单偏好 | `HKCU\Software\New7z\Explorer` |
| 文件关联 ProgID | `HKCU\Software\Classes\New7z.*` |
| 安装状态 | `%LOCALAPPDATA%\Programs\New7z\installation.json` |
