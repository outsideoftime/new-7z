## 工作进程与安全边界

父进程通过重定向标准输入/输出发送 JSON；密码仅进入匿名管道，不进入命令行、请求临时文件或日志。进度消息需要父进程确认，取消先通知工作进程，5 秒未退出则终止。Windows Job Object 将单工作进程内存限制为 2 GiB，并在父进程退出时结束工作进程。拖放回调的托管状态随原生 IDataObject 最后一个引用释放，Shell 进度界面保持在原 COM apartment。

解压默认最多 1,000,000 条目、64 GiB 单文件、100 GiB 累计输出；API 的 `ExtractionLimits` 可指定更严格或经调用方批准的不同上限。检查使用无符号溢出安全累加；底层输出流还有实际字节上限，不只依赖显示元数据。默认上限不是磁盘空间预留，也不是压缩比启发式；没有自动递归展开嵌套压缩包。

归档的 `Zone.Identifier`（最多 64 KiB，完整内容）在每个临时输出提交之前复制，不能保留时该文件不提交；嵌套归档继续传播，跳过保留原目标 Zone，替换/重命名继承来源。修改归档也保留其 Zone。没有来源 Zone 时不凭空添加。MotW 路径回归在本机 NTFS 上运行，其他文件系统、网络共享和组织策略仍需专项验收。

## 正式签名使用

```powershell
./scripts/build-installer.ps1 -RequireSignature -SigningCertificateThumbprint <40位证书指纹>
```

证书需已由发布者配置到当前用户证书存储，含可访问私钥、受信任链与 Code Signing EKU。默认时间戳服务可用 `-TimestampServer` 替换。脚本不会生成、导入或信任证书。实际签名流程依据 [Microsoft 包签名说明](https://learn.microsoft.com/en-us/windows/win32/appxpkg/how-to-sign-a-package-using-signtool) 和 [SignTool 校验说明](https://learn.microsoft.com/en-us/windows/win32/seccrypto/signtool)。

证书就绪后仍需在关闭开发者模式、没有开发注册的干净 Windows 11 普通账户验收：首次安装现代菜单、修复、升级、卸载、签名/时间戳有效性及兼容回退。本轮仅验证无证书的发布门禁，不能将构建成功等同于正式签名完成。
