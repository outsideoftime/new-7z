# 右键菜单与任务窗口设置

日期：2026-11-04。入口：主程序左侧「设置」。

## 使用方式

「资源管理器右键菜单」包含 New7z 总开关和八项命令勾选。修改后点击「应用菜单设置」，保存结果就地显示。关闭总开关保留命令选择；重新打开可沿用。开启菜单时必须至少选择一个命令，且菜单仍会根据单个归档、多个归档、普通文件/文件夹自动筛选；没有适用命令时隐藏 New7z 入口，避免空菜单。

「任务弹出窗口」→「任务成功后」可选：

- **手动关闭（默认）**：成功后保留结果、打开文件夹和关闭按钮。
- **自动关闭**：全部任务成功完成后退出小窗口。失败、取消或读取设置异常时保留窗口。

关闭方式选择后立即保存；保存失败会恢复原选项并显示原因。它只影响右键快捷任务窗口，不关闭正常主界面。已完成并保留的旧窗口不会因为设置切换而突然退出。

用户后续确认不再要求关闭 Windows 自带菜单，因此系统「压缩到…」等入口保持原样。

## 实现

原生设置页由 `MainWindow.Settings.cs` 维护，读取/保存由 Core 的 `ExplorerPreferencesStore` 负责。配置位于当前用户 `HKCU\Software\New7z\Explorer`：`MenuEnabled`、`Commands`、`AutoCloseOnSuccess`，均为 DWORD。缺省为 1、255、0；不需要创建配置便能保持默认行为。

`native/New7z.Shell.cpp` 在 GetState / EnumSubCommands 读取同一位置，不缓存配置。已打开的菜单视图不动态变化，重新打开菜单读取新值；部分 Explorer 窗口可能需要重新打开。菜单关闭配置不卸载组件，之后可以直接重新开启。

`ShellTaskWindow` 只在成功完成后读取自动关闭策略，设置读取失败退回手动关闭；错误和取消不会触发自动关闭。保留无系统标题栏、内容头部拖动与底部关闭行为。
