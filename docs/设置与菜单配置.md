# 右键菜单与任务窗口设置

日期：2026-11-05。入口：主程序左侧「设置」。

## 使用方式

「资源管理器右键菜单」包含 New7z 总开关和八项命令勾选。修改后点击「应用菜单设置」，保存结果就地显示。关闭总开关保留命令选择；重新打开可沿用。开启菜单时必须至少选择一个命令，且菜单仍会根据单个归档、多个归档、普通文件/文件夹自动筛选；没有适用命令时隐藏 New7z 入口，避免空菜单。

「任务弹出窗口」→「任务成功后」可选：

- **手动关闭（默认）**：成功后保留结果、打开文件夹和关闭按钮。
- **自动关闭**：全部任务成功完成后退出小窗口。失败、取消或读取设置异常时保留窗口。

关闭方式选择后立即保存；保存失败会恢复原选项并显示原因。它只影响右键快捷任务窗口，不关闭正常主界面。已完成并保留的旧窗口不会因为设置切换而突然退出。

「Windows 自带压缩菜单」可隐藏 Windows 11 24H2 及更新版本的「压缩到」右键菜单。此项只作用于当前用户，立即保存并通知资源管理器刷新；如菜单仍显示，需要重新启动资源管理器。Windows 11 24H2 以下版本会禁用此选项。

## 实现

原生设置页由 `MainWindow.Settings.cs` 维护，读取/保存由 Core 的 `ExplorerPreferencesStore` 负责。配置位于当前用户 `HKCU\Software\New7z\Explorer`：`MenuEnabled`、`Commands`、`AutoCloseOnSuccess`、`HideWindowsCompressMenu`，均为 DWORD。缺省为 1、255、0、0；不需要创建配置便能保持默认行为。

隐藏 Windows 菜单时，仅在当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked` 中屏蔽 Windows 11「压缩到」命令的 CLSID `{7AE6900F-6EB0-44A2-9CA1-DB2F7EF352AF}`。New7z 会先备份该值原有的类型与内容；用户关闭选项时恢复原值。若检测到其他程序在此期间修改该值，New7z 保留外部修改，不覆盖它。备份子键丢失时，只在屏蔽值确为 New7z 写入的标记（`New7z:` 前缀）时才删除，不会改掉其他程序的项。卸载时也会恢复 New7z 自己设置的值，不改动其他菜单项，也不会为从未使用过该功能的用户新增配置值。

`native/New7z.Shell.cpp` 在 GetState / EnumSubCommands 读取同一位置，不缓存配置。已打开的菜单视图不动态变化，重新打开菜单读取新值；部分 Explorer 窗口可能需要重新打开。菜单关闭配置不卸载组件，之后可以直接重新开启。

`ShellTaskWindow` 只在成功完成后读取自动关闭策略，设置读取失败退回手动关闭；错误和取消不会触发自动关闭。保留无系统标题栏、内容头部拖动与底部关闭行为。
