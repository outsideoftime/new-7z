实现：`ArchiveEngine.ExtractAsync` 从逐文件 `NzExtract` 改为 `NzExtractBatch`：一次打开归档，按升序索引一次调用 7-Zip `Extract`，保留固实解码状态；整次解压放在一个后台任务中，全部路径预检完成后才创建输出。原生层重新检查索引、条目类型和大小上限；逐文件写入唯一临时文件，CRC 成功并关闭句柄后再提交；重命名/跳过/替换策略、时间戳、取消与托管回调异常清理保持。进度通知限制为约每 50 ms 一次，修改时间通过已打开的输出句柄设置，路径重解析点检查改为每级组件一次 `GetFileAttributesW`。预览仍走单文件读取接口。

测试：`scripts/test.ps1` **172 项通过**（新增批量无序选择、固实块子集、冲突策略、时间戳、空文件、加密 7z / AES ZIP、错误密码、CRC 损坏、中途取消、托管回调异常、大小限制与全量路径预检）；`scripts/test-shell-preferences.ps1` **15 项通过**；1.0.1 裁剪载荷 `--verify-ui` **PASS**（设置分类、任务卡片、文件名绑定、44 字符文本、512×512 图片）。

安装包：`artifacts/releases/New7z-1.0.1-x64-Setup.exe` **23.36 MiB**（24,490,767 字节），SHA256 `649024DCC480D831C226AB5E6B12328C00EDA59CB6CEBD9BCD4930EF02026594`；运行载荷 **76.67 MiB**（80,396,319 字节，181 个文件），BuildId `c5ba0022abda`。

性能：本机实测 RAR（5,858 个文件、494 个目录）194.482 → 14.687 秒；512 文件、32 MiB 样本 ZIP 1.418 → 0.626 秒、固实 7z 11.154 → 0.615 秒、TAR 3.896 → 0.601 秒；真实应用入口（`--shell-request` / `extract-named`）解压同一 RAR 从进程启动到最后一个文件提交 18.321 秒，逐文件 SHA-256 与旧版一致。未控制冷缓存，也未与 Windows 自带解压在相同条件下对比。

验证边界：本轮未重跑隔离安装器端到端测试与拖动解压测试（菜单与安装脚本未改动）；未做真实鼠标键盘界面走查；性能数字仅代表本机本地缓存条件。
